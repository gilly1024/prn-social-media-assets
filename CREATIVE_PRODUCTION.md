# PRN creative production — required agent entry point
**Effective:** 25 November 2026. Applies to every agent creating or editing PRN imagery, social graphics, animation, video, adverts, product demonstrations, explainers, music or sound.

## Authority and access
Read the current [Brand Voice](BRAND_VOICE.md), [Social Content Engine](SOCIAL_CONTENT_ENGINE.md), [Video Style Guide](VIDEO_STYLE_GUIDE.md), [Social Prompt Library](SOCIAL_PROMPT_LIBRARY.md), and [Video Export and Playback Lock](VIDEO_EXPORT_AND_PLAYBACK_LOCK.md) as applicable. Existing owner instructions, element-authorisation, factual accuracy, licensing, publishing and spending restrictions remain in force. This is an execution companion, not a replacement brand guide.

Load the shared **prn-video-production** skill and **PRN Video Production Toolkit** on the authorised production computer. Project instructions provide its location and the private **LOCAL_CREATIVE_TOOLCHAIN.md** inventory. The inventory records actual local software versions, locations, control and export test status; it changes as tools evolve. Read the toolkit's 00-START-HERE.md, SKILL.md, relevant workflows and quality gates. Do not assume a cloud-only agent can access local files; use authorised local access or give a precise handover. The detailed local inventory, unpublished film masters and private source projects are deliberately not copied to this public repository.

## Choose the production lane before the tool
| Job | Candidate tools/approach |
| --- | --- |
| App feature demonstration | Authentic screen capture, Blender/Python, Remotion; motion demonstrates each real feature. Label designed simulation. |
| Cinematic platform, website or logo film | Blender with real brand/product assets, individual shot design, camera/light/motion, original or licensed audio. |
| Coded motion/graphic advert | HyperFrames/GSAP, Remotion, Motion Canvas, Cavalry where operational. |
| Real-footage documentary | Resolve/Fusion/Fairlight, Kdenlive, CapCut or equivalent. |
| Posters, carousels, images | Affinity, Inkscape, SVG/Python and appropriate verified image-editing tools. |
| Accurate equipment visualisation | FreeCAD and Blender when dimensions matter. |
| Audio, narration, captions | Csound, Audacity, Surge XT, speech/transcription tools when suitable and authorised. |
| Export and QA | FFmpeg/FFprobe, native editor and human playback. |

These are candidate routes, not guaranteed connections or current local installation claims. Consult the private inventory and verify the required version, control route, export, rights, disk and concurrent workload. Prefer proven local production where suitable, rather than unnecessary paid generation. A registered bridge does not prove live operation. No speculative paid generation or unapproved media transfer.

## Learn from accepted work
For app adverts, read the toolkit's APP-ADVERT-STANDARD.md and SLS-ADVERT-POSTMORTEM-LESSONS.md; watch the accepted SLS benchmark. For website/platform/logo-led cinema, read CINEMATIC-WEBSITE-ADVERT-STANDARD.md and watch the accepted PRN cinematic benchmark. Both live under the toolkit's 01-Production-Workflow directory; the private standards specify exact master/source locations and recorded approval status.

- Define audience, purpose, hook, visual treatment, CTA and a storyboard before building.
- Show features happening, not just captions over stills. Use authentic controls/assets, clearly label simulated visualisations and verify every claim. Never invent sensor readings, ghost evidence, authentic locations or app behaviour.
- Use original shot design and purposeful motion. Avoid repeated screenshot slideshows, identical transitions, unreadable text, arbitrary filters and generic audio. Maintain genuine logo identity; a permitted animation must be based on approved artwork.
- Match length and aspect ratio to the active brief and platform. Micro-ad guidance remains for its own lane, not all films. Reframe native versions rather than blindly crop.
- Build a short playable representative proof before costly full production. Review picture, motion, text, audio and claim-to-shot agreement. Apply existing approvals; do not add unspecified elements or treat benchmark approval as approval of a new cut.
- Preserve editable projects, originals, source and licence records, scripts, separate stems, export instructions and QA. Follow [Video Export and Playback Lock](VIDEO_EXPORT_AND_PLAYBACK_LOCK.md) for compatible review delivery. Technical checks are not creative approval; document actual viewing/listening limitations.

## Continuous improvement
When a new production is accepted, or a method materially fails, record the date, specific cut and approval status, source project, reproducible method, tool/version, what worked, what failed, correction, remaining limits and reuse conditions in the private toolkit. Update the local inventory only on evidence, distinguishing downloaded, installed, connected, launch-tested and export-tested. Do not silently upgrade working dependencies or interrupt other agents. Retain rejected work as lessons, not approved references. Escalate genuine brand/standard changes to the canonical guides with owner direction. Preserve private materials; never publish or spend merely because a tool or precedent exists.
