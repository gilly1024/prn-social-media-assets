# Grundisburgh Devil: source-verified TikTok slides (final correction)
Seven vertical 1080 x 1920 JPG slides telling the **Warning to Janglers** story at St Mary's Church, Grundisburgh. Only genuine photographs of this church, by Michael Garlick / Geograph, have been used.

**Correction:** Removed the St Christopher mural from Slide 6: that is a separate medieval image and was a confusing visual for this story. Slide 6 now uses the actual 'Warning to Janglers' fragment and explains the alternative St Margaret-and-dragon reading. Slide 1 poses a question rather than asserting the interpretation as a documented fact.

- `slide_01.jpg` ... `slide_07.jpg`: individual full-quality 1080 × 1920 pictures.
- `grundisburgh_tiktok_7_slides.zip`: compact JPEG set of all seven 1080 × 1920 slides plus credits.
- `contact_sheet.jpg`: preview.
- `PHOTO_CREDITS.txt`: photographer, photo sources and licence.
